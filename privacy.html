Privacy Policy

Last updated: September 22, 2026

What this app is

GDrive MCP Server is a personal, self-hosted tool. It runs on its owner's own computer and connects an AI assistant to the owner's own Google accounts. It is not offered to the public and has no users other than its owner.

What data it accesses

With the owner's consent through Google sign-in, the app may access Gmail messages and labels, Google Docs the app creates or is given access to, and Google Calendar events, using the Gmail, Google Docs, Google Drive, and Google Calendar APIs.

How data is used and stored

  • Data is read and written only to carry out actions the owner requests, such as searching mail, labeling threads, drafting replies, editing documents, and managing calendar events.
  • OAuth tokens are stored only on the owner's computer. No Google user data is sent to, stored on, or processed by any third-party server operated by this app.
  • No data is sold, shared, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account permissions page. Stored tokens can be deleted from the owner's computer at any time.

Contact

Questions about this policy can be sent to the developer contact email listed on the Google sign-in consent screen.
